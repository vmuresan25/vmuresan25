## ☀️ Featured Project

### Photovoltaic Monitoring System

A real-world monitoring system developed for a **5 kWp residential photovoltaic installation**.

The system combines:

- Real vs. theoretical photovoltaic production analysis
- Solar irradiance and meteorological data
- Optical sensing for panel soiling monitoring
- ESP32-based data acquisition
- Automated monitoring running on a Linux server
- Persistent anomaly detection and alerts
- Historical data collection for future machine-learning models

The project is currently evolving toward a **data-driven system capable of estimating soiling losses and supporting automated cleaning decisions without requiring a physical soiling sensor at deployment sites**.
